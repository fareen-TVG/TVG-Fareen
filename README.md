# TalentVerse Global website

Static site — upload the whole folder to any static host. No server code.

## Editing the site

Every page is generated by one script:

```
python3 tools/build_site.py
```

- **Speakers** — edit `data/speakers.json` (name, slug, category, title, bio, photo). Put photos in `Images/speakers/<slug>.jpg` (portrait, about 600×800).
- **Page copy, navigation, footer, featured speakers** — edit `tools/build_site.py`.
- **Look and feel** — `css/styles.css` (brand colours are at the top). Behaviour (menu, search, forms) — `js/main.js`.

Then re-run the script; it rewrites all `.html` files and `sitemap.xml`. Don't edit the generated HTML by hand.

Fees and locations from the internal roster sheet are deliberately **not** stored or published.

## Hosting

The site is hosted on **GitHub Pages** from the `main` branch (root folder). The build script also writes:

- `CNAME`: the custom domain, `talentverseglobal.com`.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.
- `404.html`: shown for any missing page. Its links start with `/` so they work at any depth.
- Forwarding pages for old URLs (`about.html`, `journal.html`, `navtej-sarna.html`). Add more in `REDIRECTS` in the build script.

## Launch checklist

1. **Domain** — canonical URLs, social tags, `sitemap.xml` and `robots.txt` assume `https://talentverseglobal.com` (`SITE` in the build script).
2. **Google Search Console** — verify the domain and submit `sitemap.xml`.
3. **Google Analytics 4** — the GA4 tag (`G-8Z79QEXPCV`, set as `GA4_ID` in the build script) is on every page. Forms already fire a `generate_lead` event; the thank-you page is another conversion signal.
4. **EmailJS** — forms send `first_name`, `last_name`, `email`, `contact_number`, `organisation`, `event_date`, `audience_size`, `topic`, `budget`, `event_details`, `page`. The speaker requested (and, for roster applications, topics and profile link) is added to the top of `event_details`. Send a test enquiry from each form.
5. **Privacy policy** — have `privacy.html` reviewed before launch.
6. **Permissions** — confirm you may list each speaker and use their photo.
